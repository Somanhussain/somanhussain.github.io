# Abdul Asif A. — Student Portfolio

A responsive personal portfolio made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, colors and responsive styling
- `script.js` — mobile navigation, reveal effects and current year

## Preview locally
Open `index.html` in a browser. For a better development workflow, open this folder in Visual Studio Code and use the Live Server extension.

## Personalise before publishing
1. Check your name, course and college details.
2. Replace `your.email@example.com` with your real email address.
3. Add your real GitHub and LinkedIn profile URLs.
4. Replace sample project cards with projects you have actually completed.
5. Update the skills list to match your current ability.
6. Add a profile photo if you want one (optional).

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for deployment. Your site should appear at `https://YOUR-USERNAME.github.io/`.

GitHub Pages hosts static HTML, CSS and JavaScript. A public repository is needed for GitHub Free. See https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
